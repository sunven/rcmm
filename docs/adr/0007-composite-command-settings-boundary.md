# Separate composite command authoring from Finder menu placement

组合命令继续作为 Finder 中的单个菜单项，但创建、详细编辑和单项启停收口到独立的“组合命令设置”区域；“Finder 菜单”区域继续提供所有菜单项的统一排序、启停和运行状态总览。两处引用同一条菜单项记录：已有组合命令自动出现在组合命令设置中，删除和跨页编辑都作用于同一记录。新建空白组合命令或使用模板会立即创建一条用户配置；配置不完整时保留在设置中但不可发布到 Finder。内置组合命令以模板形式创建为独立的用户配置，不与模板保持绑定；缺少模板依赖时仍展示模板但不可创建。这样可以提供专门的组合命令工作流，同时避免维护两份配置或把组合命令误建模为 Finder 子菜单容器。
